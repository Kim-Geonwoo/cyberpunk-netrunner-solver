# 동작 원리

`cyberpunk-netrunner-solver`가 화면을 캡처하고, 퍼즐 구조를 복원하며, 최적의 경로를 찾아 안전하게 오버레이를 표시하는 과정입니다.

## 화면 캡처

- 단축키를 누르면 현재 포그라운드 창이 위치한 모니터 화면을 DXGI 화면 복제 방식으로 캡처합니다.
- DXGI 화면 복제가 불가능하거나 지원되지 않는 환경에서는 GDI 방식으로 화면을 캡처합니다.
- 화면 캡처와 문자 인식 전체 과정에는 10초의 시간 제한이 적용됩니다. 문자 인식 호출 사이뿐 아니라 격자 맞추기와 글자 모양 비교 도중에도 제한을 확인해 계산을 멈춥니다.

## 다국어 문자 인식과 격자 복원

- **다국어 문자 인식 엔진 동시 사용**: Windows에 설치된 모든 문자 인식 언어를 동시에 실행하여 브리치 프로토콜에서 쓰이는 코드 값(`1C`, `55`, `7A`, `BD`, `E9`, `FF`)만 골라냅니다. 따라서 게임의 언어 설정과 상관없이 동작하며, 데몬 이름처럼 다른 언어로 된 글자는 자동으로 걸러집니다.
- **가로 띠 재스캔**: 전체 화면에서 행렬 격자를 찾지 못하면 화면을 여러 개의 가로 띠 영역으로 나누어 다시 읽습니다.
- **줄 재스캔과 글자 모양 비교**: 행렬 안에 빈 칸이 남아 있으면 해당 줄 영역만 다시 읽습니다. 다시 읽은 뒤에도 비어 있는 칸은 같은 화면에서 이미 정상적으로 읽힌 다른 칸들의 글자 모양(글리프)과 비교하여 채우며, 끝내 판독하지 못한 칸은 `?`로 남깁니다.
- **격자 확장**: 가장자리의 줄이나 열을 처음에 놓쳤더라도 이미 읽힌 칸들의 글자 모양과 대조하여 격자를 바깥쪽으로 넓혀 나갑니다(최대 8×8 크기까지 확장).
- **시퀀스 줄 복원**: 시퀀스 목록에서 누락된 줄이 있으면 확인된 줄 사이의 간격을 바탕으로 위치를 짐작한 뒤 글자 모양 비교를 통해 빈자리를 채웁니다.

## 버퍼 크기 판독과 마우스 커서 감지

- **버퍼 크기 자동 감지**: 코드 행렬 위쪽에 위치한 빈 버퍼 칸의 테두리 상자 개수를 검출하여 버퍼 크기를 알아냅니다. 화면에서 버퍼 크기를 읽어내지 못하면 이전에 성공했던 마지막 버퍼 크기 설정을 사용합니다.
- **마우스 커서 가림 감지**: 게임 마우스 커서의 청록색 강조 표시가 판독되지 않은 칸 주변이나 시퀀스 코드 영역 위에 나타나면, 억지로 부정확한 경로를 그리지 않고 '마우스 커서가 코드를 가렸습니다'라는 실패 안내를 표시합니다.

## 풀이 규칙과 경로 탐색

- **이동 규칙**: 첫 번째 선택은 항상 코드 행렬의 맨 윗줄에서 시작하며, 이후 직전 선택 칸을 기준으로 열과 행을 번갈아 가며 고릅니다. 한 번 방문한 칸은 다시 고를 수 없습니다.
- **시퀀스 완료 조건**: 목표 시퀀스는 버퍼 목록 안에서 중간에 끊김 없이 연속으로 나열되어야 완료로 처리되며, 여러 시퀀스가 서로 겹치는 코드를 공유할 수 있습니다.
- **우선순위와 평가 기준**:
  - 위쪽 데몬 절대 우선 원칙을 적용합니다. 위쪽 데몬 하나를 완료하는 것이 아래쪽 여러 데몬을 완료하는 것보다 항상 우선합니다.
  - 완료 점수가 같은 경로가 여럿이라면 버퍼를 더 적게 쓰는 경로를 우선하고, 그다음으로는 이동 선이 덜 겹치는 경로, 그다음으로는 전체 이동 거리가 더 짧은 경로를 선택합니다.
- **조합 가지치기와 시간 제한**:
  - 단독으로도 완성이 불가능한 시퀀스가 포함된 조합은 탐색 대상에서 건너뜁니다.
  - 경로 탐색 알고리즘에는 1초의 시간 제한이 적용되며, 1초를 넘기면 그때까지 찾은 최선의 경로와 함께 '시간 초과' 상태를 표시합니다.

## 안전 설계

- **게임 무간섭**: 게임 프로세스, 게임 파일, 메모리에 일체 접근하지 않으며 순수하게 화면 이미지만 읽어 판독합니다.
- **안전한 입력 감지**: 저수준 키보드 후킹을 사용하지 않고 30ms 간격으로 등록된 키 상태만 폴링하여 단축키 입력을 확인합니다.
- **자동 클릭 없음**: 게임 내 조작을 자동으로 수행하거나 클릭 이벤트를 게임에 전송하지 않습니다.
- **입력 상한**: 화면이 코드처럼 읽히는 글자로 가득 차도 멈추지 않도록 한 번의 판독에 쓰는 서로 다른 코드 토큰을 4096개, 한 버퍼 길이에서 만드는 시퀀스 배치 패턴을 10만 개, 이미지 한 변을 16384픽셀까지로 제한합니다. 같은 자리에서 같은 코드로 거듭 읽힌 글자는 한 토큰으로 합치고 읽힌 횟수만 투표에 더합니다. 정상 퍼즐(격자 4~8칸, 시퀀스 6줄 이하, 버퍼 1~12칸)은 이 상한에 닿지 않습니다.
- **반응하는 패널**: 패널에서 칸·시퀀스·우선순위·버퍼를 고치면 풀이를 화면 스레드 밖에서 다시 하고, 끝나기 전에 또 고치면 앞선 풀이는 취소합니다.
- **오버레이 투과**: 오버레이 창은 게임 창의 포커스를 뺏지 않으며, 화면 위에 표시되는 번호와 선 그래픽은 마우스 클릭을 그대로 통과시켜 게임 조작을 방해하지 않습니다. 또한 화면 캡처 및 화면 녹화 시에도 오버레이가 정상적으로 기록됩니다.
